# NEXO V1

Web estática con HTML5, CSS3, JavaScript ES6+, JSON y LocalStorage.

## Ejecutar
Abre la carpeta en VS Code y usa Live Server. No abras los HTML con doble clic si vas a usar JSON/fetch, porque el navegador puede bloquear las peticiones file://.

## Incluye
- Home
- 6 minijuegos
- 8 categorías de quizzes
- 2 páginas de retos
- 7 herramientas
- 6 tests
- XP, niveles, logros, estadísticas y racha
- Diseño responsive para móvil, tablet y PC

## Limitaciones de esta V1
- El perfil y las puntuaciones son locales al navegador.
- No existe todavía ranking global ni cuentas multiusuario.
- El QR usa QRCode.js desde CDN.
